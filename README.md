# 🚀 Featured Project

## 🌱 Green AI Data Center Energy Management

An intelligent **AI-based Data Center Energy Management and Optimization system** designed to reduce power consumption, electricity cost, and carbon emissions in AI/GPU-based data centers.

### 🎯 Objective

To use Machine Learning to predict data-center energy parameters and enable intelligent energy management based on:

- GPU utilization
- CPU utilization
- Ambient temperature
- Solar generation
- Battery state of charge
- Electricity tariff
- Number of active servers
- Time of day

### 🧠 Machine Learning

The system uses a **Random Forest Regression** model to predict:

- ⚡ Total Power Consumption
- 💰 Electricity Cost
- 🌍 Carbon Emission

### 📊 Model Performance

- **R² Score:** 0.9731
- **MAE:** 11.6192

### 🔌 Hardware Integration

The ML system is designed to work with an **ESP32-based control system** for real-time monitoring and control.

The hardware prototype includes:

- ESP32
- Server/load indicators
- RGB LEDs
- Servo motor
- Energy-aware control logic

### 🌍 Key Idea

> **Predict → Analyze → Optimize → Control**

The system aims to intelligently manage data-center resources while maintaining performance and reducing unnecessary energy consumption.
